# Guest Feed Brand Tokens

Extracted from TelegramSocialWall and adapted for wedding marketing usage.

## Core Palette
- `--color-bg: #f9f5ef`
- `--color-bg-mid: #f3ede4`
- `--color-surface: #fffdf8`
- `--color-surface-elevated: #fffefa`
- `--color-surface-soft: #f0e8df`
- `--color-text: #1f1812`
- `--color-text-muted: #5c4f44`
- `--color-border: #e2d6c8`
- `--color-accent: #8b5a4a` (event accent example from TelegramSocialWall config)

## Typography
- Display font: `"Cormorant Garamond", Georgia, "Times New Roman", serif`
- Body font: `"Roboto", system-ui, -apple-system, "Segoe UI", sans-serif`

## Usage Guidelines
- Use accent only for key conversion elements and headings.
- Use elevated/soft surfaces for card hierarchy.
- Keep body text dark on light background for readability.
- Keep the subtle dot + vertical gradient canvas from TelegramSocialWall for visual continuity.
